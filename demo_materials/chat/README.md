# 对话框体验材料包（合成演示数据）

三份材料精确对应 `tools/material_check.py` 的三类门控关键词：

| 文件 | 覆盖门控类别 | 关键内容 |
|---|---|---|
| `保单信息.md` | 保单信息（关键词"保单"） | 保单号 POL-2024-001、车损险+三者险 |
| `事故现场照片.md` | 事故或出险证明（关键词"事故/现场照片"） | 2024-06-15 停车场刮擦、左前门划痕 |
| `维修发票.md` | 费用或损失凭证（关键词"发票"） | INV-2024-0615、￥1,286.40 |

## 使用方法（浏览器）

1. 打开 http://127.0.0.1:8001/ ，左侧新建会话
2. 先输入：`我车在停车场被刮了，要理赔` → 体验第 1 轮追问缺材料
3. 点 📎 附件按钮，依次上传本目录 3 个 `.md` 文件（一次可选多个）
4. 再输入：`材料齐了，帮我审核` → 材料门控通过（material_status: complete），助手输出三份单证预审表格
5. 继续追问：`车损险都保什么` → 体验意图切换到条款咨询（RAG）

## 已实测验证（2025-06 本机）

- 附件识别：3 份 .md 全部识别成功，置信度 0.90–0.95
- 材料齐全场景：material_status=complete，助手生成预审表格并提示"演示材料不可用于正式理赔"
- 缺材料场景：material_round=1/3，追问三 类缺失材料
