📎 单证与证据如何进入链路

  1. 对话附件：工作台上传 PDF/DOCX/文本/图片 → POST /api/documents/analyze 内存解析（最多 6 份，不落盘）；图片走 vision 模型识别。
  2. 材料审核：按附件类型核查三类材料 —— ①保单信息 ②事故/出险证明 ③费用/损失凭证；缺失则保留累计附件并回流追问，最多三轮。
  3. 进入状态机：材料补齐后（轮次清零）继续理赔链路，证据似然供置信度系统使用。

agents/observability.py 脱敏回调：意图分类 → 专家调用 → 置信度融合，形成嵌套 trace 树；工作台对话页每个节点也会推送 trace 事件（SSE）。
