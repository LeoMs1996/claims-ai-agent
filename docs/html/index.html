🚗 理赔 Agent 培训材料实现 · 项目总览

基于 LangChain 0.3 + LangGraph 的车险理赔智能审核系统：多轮对话意图识别 → 材料审核 → LangGraph 状态机 → 三专家并行审核 → 置信度融合 → 决策建议 / 人工复核（HITL）

Python 3.10+ LangChain 0.3.14 LangGraph + Send 并行 FastAPI :8001 Milvus 混合检索 Redis 记忆持久化 LangFuse v2 追踪 Prometheus 指标
🏠 项目总览 🏗️ 架构与模块 🔗 完整链路 💬 对话走链路 ⚙️ API·部署·运维

📌 一句话理解这个项目

这是一个教学级但工程完整的车险理赔智能审核 Agent：用户用自然语言对话报案，系统自动识别意图、审核材料齐全性、驱动 LangGraph 状态机跑完「报案受理 → 单证核查 → 保单核验 → 三专家并行（定损/风控/判责）→ 置信度融合 → 决策建议」的完整链路；缺材料自动追问回流，高风险/低置信/大额自动转人工复核（HITL），授权审核员可携带 Key 恢复流程。

设计原则：真实模式未配置业务适配器会转人工，绝不返回假保单或虚构定损；演示数据全部显式标注 demo: true、source: 合成数据；生产环境自动禁用演示入口。
